────────────────────────────────────────────────────────────────────────────────
[LoadingView] (loading_view.dart) — 스플래시
────────────────────────────────────────────────────────────────────────────────
  ├─ (900ms 자동) ──▶ [TitleView] (/)

────────────────────────────────────────────────────────────────────────────────
[TitleView] (title_view.dart) — 타이틀
────────────────────────────────────────────────────────────────────────────────
  ├─ (화면 탭) ──▶ [LoginView] (/login)

────────────────────────────────────────────────────────────────────────────────
[LoginView] (login_view.dart) — 로그인
────────────────────────────────────────────────────────────────────────────────
  ├─ [게스트로 시작] ──▶ [MainScreen] (/main)

────────────────────────────────────────────────────────────────────────────────
[MainScreen] (main_screen.dart) — 메인 탭 컨테이너
────────────────────────────────────────────────────────────────────────────────
  ├─ [하단 탭 0: 로비] ──▶ [LobbyTab] (embedded)
  ├─ [하단 탭 1: 캐릭터] ──▶ [CharacterView] (embedded)
  ├─ [하단 탭 2: 상점] ──▶ [ShopView] (embedded)
  ├─ [하단 탭 3: 인벤토리] ──▶ [InventoryView] (embedded)
  └─ [하단 탭 4: 설정] ──▶ [SettingsView] (embedded)

────────────────────────────────────────────────────────────────────────────────
[LobbyTab] (lobby_tab.dart) — 로비
────────────────────────────────────────────────────────────────────────────────
  ├─ [언어 아이콘 탭] ──▶ 언어 선택 다이얼로그 (한국어/영어/일본어)
  ├─ [퀘스트 아이콘 탭] ──▶ [QuestView] (/quest)
  ├─ [공지 아이콘 탭] ──▶ [NoticeView] (/notice)
  ├─ [QUICK PLAY] 버튼 ──▶ [GamePlayView] (/gamePlay, arguments: 최근곡 번호)
  └─ [곡 선택] 버튼 ──▶ [StageSelectView] (/stageSelect)

────────────────────────────────────────────────────────────────────────────────
[CharacterView] (character_view.dart) — 캐릭터

5. DB 테이블 구조
================================================================================

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 테이블: users                                                          │
  ├──────────────────────┬──────────┬──────────────────────────────────────┤
  │ 필드                 │ 타입     │ 설명                                 │
  ├──────────────────────┼──────────┼──────────────────────────────────────┤
  │ id                   │ INTEGER  │ PRIMARY KEY AUTOINCREMENT           │
  │ coins                │ INTEGER  │ 보유 코인 (기본값 0)                │
  │ last_played_stage_id │ INTEGER  │ 최근 플레이 곡 (기본값 1)           │
  │ created_at           │ TEXT     │ 생성일시 (CURRENT_TIMESTAMP)        │
  └──────────────────────┴──────────┴──────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 테이블: owned_items                                                    │
  ├──────────────────────┬──────────┬──────────────────────────────────────┤
  │ 필드                 │ 타입     │ 설명                                 │
  ├──────────────────────┼──────────┼──────────────────────────────────────┤
  │ id                   │ INTEGER  │ PRIMARY KEY AUTOINCREMENT           │
  │ user_id              │ INTEGER  │ FK → users.id                       │
  │ item_id              │ TEXT     │ 아이템 ID (stage_1, effect_spark 등)│
  │ item_type            │ TEXT     │ 'song' or 'effect'                  │
  │ is_equipped          │ INTEGER  │ 0 or 1 (장착 여부)                 │
  │ owned_at             │ TEXT     │ 구매일시                            │
  └──────────────────────┴──────────┴──────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 테이블: stage_results                                                  │
  ├──────────────────────┬──────────┬──────────────────────────────────────┤
  │ 필드                 │ 타입     │ 설명                                 │
  ├──────────────────────┼──────────┼──────────────────────────────────────┤
  │ id                   │ INTEGER  │ PRIMARY KEY AUTOINCREMENT           │
  │ user_id              │ INTEGER  │ FK → users.id                       │
  │ stage_id             │ INTEGER  │ 곡 번호                             │
  │ score                │ INTEGER  │ 획득 스코어                         │
  │ max_combo            │ INTEGER  │ 최대 콤보                           │
  │ perfect              │ INTEGER  │ PERFECT 판정 수                     │
  │ good                 │ INTEGER  │ GOOD 판정 수                        │
  │ bad                  │ INTEGER  │ BAD 판정 수                         │
  │ miss                 │ INTEGER  │ MISS 판정 수                        │
  │ rank                 │ TEXT     │ 달성 랭크 (S/A/B/C/F)              │
  │ cleared              │ INTEGER  │ 1이면 클리어, 0이면 실패            │
  │ played_at            │ TEXT     │ 플레이 일시                         │
  └──────────────────────┴──────────┴──────────────────────────────────────┘

  기본 데이터:
  - users: 코인 0, last_played_stage_id = 1
  - owned_items: user_id=1, item_id='stage_1', item_type='song', is_equipped=1
