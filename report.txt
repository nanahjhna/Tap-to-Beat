  ### 4. 핵심 게임 로직                                                                                                                                                                                                   
                                                                                                                                                                                                                          
  1. 스테이지 자동 생성 및 밸런스 공식 (stage_generator.dart:12-26):                                                                                                                                                      
      • 권장 전투력: Power = 100 + (150 × n) + (10 × n²)                                                                                                                                                                  
      • 클리어 보상: Reward = 50 + (40 × n)  코인                                                                                                                                                                         
      • 보스 명칭: Forest Guardian, Goblin King, Shadow Assassin, Flame Dragon, Void Behemoth 5종 순환 매핑                                                                                                               
      • 해금 조건: stageNum <= currentMaxStage + 1 (현재 하드코딩 기준 최고 스테이지 5까지 해금)                                                                                                                          
  2. 전투 진행 및 승패 판정 (game_play_view.dart:12-25):                                                                                                                                                                  
      • 제한 시간: 30초 (1초마다 _timeLeft--)                                                                                                                                                                             
      • 보스 HP: 100                                                                                                                                                                                                      
      • 공격 방식: 공격 버튼을 탭할 때마다 HP가 10씩 감소 (총 10회 연타 시 격파)                                                                                                                                          
      • 승리: 시간 내에 HP를 0으로 만들면 승리 (_finish(true))                                                                                                                                                            
      • 패배: 30초가 경과할 때까지 처치하지 못하면 패배 (_finish(false))                                                                                                                                                  
      • 일시정지: pause_overlay.dart를 다이얼로그로 띄우고 타이머를 중단/재개

  ### 5. 상태 관리 방식

  • 화면별 로컬 상태 관리 (StatefulWidget / setState):                                                                                                                                                                    
      • GamePlayView: HP, 타이머 카운트다운.                                                                                                                                                                              
      • InventoryView: 카테고리 탭, 선택된 아이템 번호, 착용 중인 아이템 Set(_equipped).                                                                                                                                  
      • QuestView: 보상 수령 여부 Set(claimed).                                                                                                                                                                           
      • MainScreen: 현재 하단 탭 인덱스(_currentIndex).                                                                                                                                                                   
  • (참고: Provider, Riverpod, Bloc, GetX 등의 전역 상태관리 라이브러리는 사용하지 않고 순수 Flutter 기능만 사용 중)

  ### 9. 실행할 때 문제가 생길 가능성이 있는 부분 (Critical)                                                                                                                                                              
                                                                                                                                                                                                                          
  │ Warning                                                                                                                                                                                           
  │ 1. iOS 기기/시뮬레이터 실행 시 즉시 크래시 위험 (AdMob 설정 누락)                                                                                                                                                     
  │ main.dart에서 MobileAds.instance.initialize()를 호출하고 있으나, Info.plist에 AdMob App ID(GADApplicationIdentifier)가 등록되어 있지 않습니다. 이 상태로 iOS 빌드 및 실행 시 시작과 동시에 **네이티브                 
  │ 크래시(SIGABRT)**가 발생합니다.                                                                                                                                                                                       
                                                                                                                                                                                                                          
  │ Caution                                                                                                                                                                                           
  │ 2. 실제 AdMob 광고 단위 ID 하드코딩                                                                                                                                                                                   
  │ ad_banner_widget.dart:17 및 AndroidManifest.xml:14에 실제 구글 계정의 라이브 AdMob ID가 포함되어 있습니다. 테스트 기기 등록 없이 디버깅을 계속하면 구글 정책 위반(무효 트래픽)으로 계정이 제재될 수 있으므로 주의가   
  │ 필요합니다.                                                                                                                                                                                                           
                                                                                                                                                                                                                          
  │ Note                                                                                                                                                                                           
  │ 3. 로그인 연동 SDK 부재                                                                                                                                                                                               
  │ 현재 소셜 로그인(Google, Apple)은 UI와 로컬 플래그 저장만 구현되어 있으며, 실제 인증 SDK(google_sign_in, sign_in_with_apple, firebase_auth 등)는 아직 연동되어 있지 않은 목업(Mock) 상태입니다.
