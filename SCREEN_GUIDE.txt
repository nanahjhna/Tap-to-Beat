🎮 게임 개요
TapToBeat는 하이라이프식 4키 리듬게임으로, 화면 아래에서 올라오는 노트에 맞춰 정확히 타이밍을 맞춰야 하는 타입의 게임입니다.
🎵 주요 콘텐츠
- 5개 곡이 준비되어 있습니다:
- Mikoshi Mayhem
- Twilight Highway
- Fighting Spirits
- Unyielding Heart
- (그 외 추가 곡들)
- 각 곡당 110개 이상의 비트로 구성된 차트가 있으며, BPM과 난이도가 다릅니다.
🕹️ 플레이 방식
- 4키 시스템: D / F / J / K 키(또는 모바일 터치)를 사용해 4개 레인의 노트를 타격
- 판정 시스템:
- PERFECT (±65ms, +300점, 체력 회복)
- GOOD (±125ms, +100점, 체력 소폭 회복)
- BAD (±200ms, +50점, 체력 감소 + 콤보 리셋)
- MISS (노트 미히트, 체력 대폭 감소 + 콤보 리셋)
- 난이도: EASY / NORMAL / HARD 3단계 (차트 선택 방식이 다름)
- 콤보 시스템: 연타 성공 시 콤보가 쌓이고, BAD/MISS 시 초기화
🏗️ 주요 기능
기능	설명
🎯 스테이지 선택	앨범 자켓 형태로 곡을 선택, 난이도별 플레이
📊 결과 화면	S/A/B/C/F 랭크, 점수, 정확도%, Max Combo, 판정별 집계
🛒 상점	곡 구매, 음원 팩, 비트 코인, 에너지, 광고 제거
🎨 인벤토리	노트 스킨(네온/마츠리/사이버/사쿠라/8Bit) 및 타격 이펙트 커스텀
📋 퀘스트/업적	일일 미션(풀콤보, 퍼펙트 횟수 등) 및 보상
⚙️ 설정	BGM/SFX 볼륨, 판정 타이밍 싱크 오프셋(-100ms~+100ms), 계정 연동
🌐 다국어	한국어 / 영어 / 일본어 지원
👤 로그인	Google / Apple / 게스트 로그인
📱 광고	AdMob 배너 광고 연동

간단히 말해, 일렉트로니카/트랜스 계열의 음악에 맞춰 4개 키를 타이밍 맞춰서 치는 리듬게임이며, 스킨 수집, 퀘스트, 순위 시스템 등 RPG적인 요소도 결합된 프로젝트입니다. 🎵🔥

2. 4키 리듬게임 플레이 핵심 사양 (GamePlayView)

- 입력 방식: 키보드 D, F, J, K 및 모바일 하단 4버튼 터치 / 트랙 탭 지원
- 판정 시스템:
  * PERFECT (±65ms, +300점, 체력 +3)
  * GOOD (±125ms, +100점, 체력 +1)
  * BAD (±200ms, +50점, 체력 -3, 콤보 리셋)
  * MISS (노트 놓침, 체력 -7, 콤보 리셋)
- 음원 재생: MikoshiMayhem.mp3 오디오 동기화 및 Stopwatch 정밀 폴백
- 게임오버 / 클리어 시 상세 분석(Rank, Accuracy %, Max Combo, 판정별 개수) 결과창 연동
